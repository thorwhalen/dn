# dn

Tools for markdown parsing and generation.

### Modules

| [`ebook`](dn.ebook.html.md#module-dn.ebook)   | Convert ebook formats (EPUB, MOBI, AZW3, FB2, LIT, ...) to markdown.   |
|--------------------------------------------------------------------------|------------------------------------------------------------------------|
| [`ocr`](dn.ocr.html.md#module-dn.ocr)       | Read text out of PDFs that have no text layer, by OCR.                 |
| [`repair`](dn.repair.html.md#module-dn.repair) | Markdown repair and cleanup utilities.                                 |
| [`src`](dn.src.html.md#module-dn.src)       | Converting things to markdown                                          |
| [`to`](dn.to.html.md#module-dn.to)         | Converting markdown to other formats                                   |
| [`util`](dn.util.html.md#module-dn.util)     | General utilities for dn                                               |
